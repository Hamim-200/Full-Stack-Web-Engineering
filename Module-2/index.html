What is Git?

Git is a Version Control System (VCS) that helps developers track changes in their code. It allows multiple developers to work together without losing previous versions.

What is GitHub?

GitHub is a cloud-based platform that stores Git repositories. It helps developers collaborate, manage projects, and share code.

Why Use Git?

  • Track code changes
  • Restore previous versions
  • Work with teams
  • Create branches
  • Manage projects efficiently

Common Git Commands

Command Description
git init Initialize a new Git repository.
git status Check the current repository status.
git add . Add all files to the staging area.
git commit -m "message" Save changes with a commit message.
git push Upload local commits to GitHub.
git pull Download the latest changes.
git clone URL Copy a repository from GitHub.

Basic Git Workflow

  1. Create a project folder.
  2. Initialize Git using git init.
  3. Create or edit files.
  4. Add changes using git add ..
  5. Commit changes using git commit.
  6. Push the project to GitHub.

Example Commands

git init
git add .
git commit -m "First Commit"
git branch -M main
git remote add origin https://github.com/username/project.git
git push -u origin main

Quick Tips

  • Commit often.
  • Write meaningful commit messages.
  • Pull before pushing.
  • Create branches for new features.
  • Never upload sensitive information.
